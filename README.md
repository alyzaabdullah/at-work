# at-work

Source for my personal site: https://alyzaabdullah.github.io/at-work/

One HTML file and my CV. No frameworks, no build step, no tracking scripts.

To add a photo, put `photo.jpg` in this folder and replace the `<div class="mono" aria-hidden="true">AA</div>` line in `index.html` with:

```html
<img class="mono" src="photo.jpg" alt="Alyza Abdullah" style="object-fit:cover">
```
